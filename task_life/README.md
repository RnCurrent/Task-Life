task planner where you can create a list of tasks/stuff that needs to be done. Completing tasks gives you xp and money. xp controls level, higher level means more stuff can be bought with the money. The user is given a virtual house that they live in. They can use the money and xp they earn to buy new furniture, items, etc. After passing a certain level, the user unlocks pets. The user can buy/adopt a pet that they will need to care for. The user can spend money on buying food, toys, and other things for the pet. The user can have only 1 pet at a time.
